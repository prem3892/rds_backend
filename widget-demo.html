Chat Widget Demo Page

This is a demo page showing how the chat widget appears on a customer's website. The chat widget should appear as a floating button in the bottom-right corner of the page.

Widget Features:

  • 🎨 Customizable colors and branding
  • 💬 Real-time messaging with Socket.IO
  • 📁 File upload support (images and documents)
  • 🏢 Department selection
  • 👤 Optional customer information collection
  • 📱 Responsive design with Tailwind CSS
  • 🔔 Unread message notifications
  • ⌨️ Typing indicators
  • 🔄 Connection status indicators
  • 📜 Chat history restoration

How to integrate:

Website owners simply need to add this script tag to their HTML:

<script src="https://your-domain.com/widgets/WIDGET_ID/script.js"></script>

Replace WIDGET_ID with the actual widget ID from your admin panel.

Socket Events Supported:

  • customer:connect_widget - Initial connection
  • customer:initiate_chat - Start new chat session
  • customer:send_message - Send messages
  • customer:typing_start/stop - Typing indicators
  • customer:mark_messages_read - Read receipts
